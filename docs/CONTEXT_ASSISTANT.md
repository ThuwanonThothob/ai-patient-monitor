# Contextual Agentic assistant

เปิดจากปุ่มลอยมุมล่างขวาของหน้าจอเพียงจุดเดียว (ไม่มีปุ่มถามแทรกตามหมวดหรือกราฟ) เพื่อเปิดหน้าต่างตรงกลางหน้าจอ
ฝั่งผู้ป่วยผูก ID กับ session; บุคลากรต้องเลือก ID ที่ได้รับสิทธิ์
เปลี่ยนหมวด/ผู้ป่วยแล้วล้างคำตอบเดิม เพื่อไม่แสดงผลผิดบริบท

`POST /api/assistant/ask` เป็น bounded read-only agent แบบ deterministic:
ตรวจสิทธิ์ → อ่าน monitor ที่มี freshness guard → อ่านผลโมเดลเดิม →
เลือกอ่านสถิติย้อนหลัง 24 ชั่วโมง/งานดูแลที่ผ่านการตรวจทาน → สรุปพร้อม tool trace
เลือกเครื่องมือตามคำสำคัญและหมวด ไม่ใช่ autonomous LLM หรือการเทรนโมเดลใหม่
ไม่เรียก Gemini และไม่ส่งข้อมูลออกไปภายนอก ส่วน Gemini เดิมแยกเป็นตัวเลือกเพิ่มเติม

รองรับค่าล่าสุด แนวโน้ม และรายการดูแล ไม่ใช่ผู้ช่วยตอบคำถามทางการแพทย์ทั่วไป
ไม่ส่งข้อความแทนผู้ใช้ ไม่แก้แผน ไม่วินิจฉัยหรือสั่งยา
คำตอบไม่อัปเดตเอง ต้องกดถามใหม่เพื่ออ่านข้อมูลล่าสุด
กราฟอาจเลือกช่วงเวลาอื่นได้ แต่ผู้ช่วยอ่านย้อนหลัง 24 ชั่วโมงตามป้ายกำกับ

กราฟรวมทั้งสองฝั่งใช้เส้นตรงและพื้นที่สีอ่อน แสดงหน่วย สเกลแยก ตัวเลขต่ำสุด/สูงสุด
แกนเวลาใช้ timestamp เมื่อมีครบ พร้อม tooltip วันที่เวลาไทยและตารางตัวเลข
ไม่มีการแทนค่าว่างด้วยศูนย์ ตัวเลขใหญ่คือค่าล่าสุดที่มีในช่วง ไม่อ้างว่าเป็นค่าสด
